# Support

[中文](SUPPORT_ZH.md)

For product usage, wiring, and board specifications, start with the
[official product documentation](https://docs.waveshare.com/ESP32-P4-WIFI6-Touch-LCD-XC)
and the repository [hardware audit](docs/HARDWARE.md).

For a reproducible repository issue, open a GitHub issue and include:

- product variant and hardware revision, if known;
- example path or Arduino sketch;
- ESP-IDF or Arduino-ESP32 version and target settings;
- build, flash, and serial-monitor output with credentials removed;
- exact reproduction steps, expected behavior, and actual behavior;
- whether the image came from source-built CI output or a factory/recovery image.

Do not publish passwords, access tokens, private keys, personal serial numbers,
or other sensitive device data in an issue. This repository does not currently
advertise a verified private vulnerability-reporting channel; do not put
credentials or unreleased vulnerability details in a public issue.
