# Security Policy

[中文](SECURITY_ZH.md)

Please do not disclose security vulnerabilities, credentials, private keys, or
other sensitive data in a public issue. Use GitHub's private vulnerability
reporting feature for this repository when it is available. If that private
channel is not enabled, contact the repository maintainers through the
organization's private support channel and include only the minimum necessary
reproduction details.

Security reports should identify the affected example or component, the target
and framework version, the impact, and a safe reproduction or mitigation. Do
not attach real customer data or device credentials.
